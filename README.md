## 🕹️ Overview

SimBrief generates realistic airline operational flight plans with ICAO routing, NOTAM checks, fuel calculations, and weather integration for MSFS, X-Plane, and P3D.

Whether you're a newcomer or a veteran, SimBrief provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **ICAO Route Planning** | Generates real-world flight routes with SID and STAR procedures |
| **Fuel Calculator** | Accurate trip fuel, contingency, and alternate fuel computations |
| **OFP Export** | Exports operational flight plans to the simulator and EFB apps |
| **Weather Integration** | Embeds live METAR and SIGMET data into the flight plan |
